A two-line robot confession for the make.fun bounty "The Robot Apology".

Line one apologizes for one specific mistake — watering the plastic plant on the desk every morning for a month, because the log said "thirsty plant" and the robot never checked whether it was alive. Line two names the lesson: a sensor reading is not the same as looking, so now it checks what is actually in front of it before acting on what the log says.

`main.py` writes the two lines to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
